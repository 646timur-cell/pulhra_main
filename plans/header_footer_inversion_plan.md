# План: Инверсия цветов Header и Footer (Strip) зон UI

## Обзор

Текущий UI PULHRA использует "Elektron mk1" look: **белый текст на чёрном фоне** (`T_TEXT = 0xFFFF` на `T_BG = 0x0000`).

**Задача:** Инвертировать две зоны:
1. **Header** (y 0..19) — белый фон, чёрный текст
2. **Footer/Strip** (y 220..239) — белый фон, чёрные точки

Остальные зоны (page, knobs, SELECT, layer map) остаются без изменений (чёрный фон, белый текст).

---

## Текущая архитектура

### Цветовая система
- `T_BG = 0x0000` (чёрный) — фон экрана
- `T_TEXT = 0xFFFF` (белый) — основной текст/чернила
- `SM_DIM_INK = 0x4208` (тусклый серый) — неактивные элементы

### Функция `sm_px_text` (sm_px.c:22)
```c
uint16_t fg = inv ? T_BG : ink;  // ← ЖЁСТКО зашито T_BG
```
При `inv=1`: рисует прямоугольник фона цветом `ink`, а текст — цветом `T_BG`. Это работает только для чёрного фона канваса.

### Функция `smd_begin` (sm_draw.c:83)
```c
cv_begin(w, h, T_BG);  // ← ЖЁСТКО зашит чёрный фон
```

### Header (`smd_header`, sm_draw.c:162)
- Рисует: трек, машину, пресет, BPM, паттерн, PLAY/STOP, REC/ARM, сообщения
- Все вызовы `sm_px_text` используют `T_TEXT` как ink

### Strip (`smd_strip1`, sm_draw.c:909)
- Рисует: 16 шагов как точки (триг = залитая 3×3, REST = полая 4×4, пусто = ничего)
- **Тактовые индикаторы** (tact indicators): `i % 4 == 0` — тусклая точка 1×1 на позициях 1, 5, 9, 13
- Плейхед: полоска 8×1 внизу
- Удержанный шаг: полоска 8×2 вверху
- Номер страницы/длина трека справа

### Strip MIXER (`smd_strip4`, sm_draw.c:868)
- 4 трека, каждый ряд точек
- Аналогичная логика с `T_TEXT`/`T_BG`

## План изменений

### Шаг 1: Модифицировать `sm_px_text` для поддержки инвертированных зон

**Файл:** `firmware/src/pulhra/sm_px.c:25`

**Изменение:** Заменить жёстко зашитый `T_BG` на `cv_bg` (текущий цвет фона канваса):

```c
// Было:
uint16_t fg = inv ? T_BG : ink;
// Стало:
uint16_t fg = inv ? cv_bg : ink;
```

**Почему это безопасно:**
- Для нормальных зон (чёрный фон): `cv_bg = T_BG = 0x0000` → поведение не меняется
- Для инвертированных зон (белый фон): `cv_bg = T_TEXT = 0xFFFF` → инвертированный текст рисуется БЕЛЫМ на чёрном прямоугольнике

### Шаг 2: Модифицировать `smd_begin` для параметризации фона

**Файл:** `firmware/src/pulhra/sm_draw.c:83`

**Изменение:** Добавить параметр `bg`:

```c
static void smd_begin(uint32_t x, uint32_t y, uint32_t w, uint32_t h, uint16_t bg)
{
    smd_x = x;
    smd_y = y;
    cv_begin(w, h, bg);
    sm_draw_px += w * h;
}
```

Обновить **всех вызывающих** (7 мест), добавив `T_BG` как аргумент:
- `smd_header` (строка 168)
- `smd_page` (строка 263)
- `smd_knob` (строка 571)
- `smd_select` (строка 632)
- `smd_map_row` (строка ~800)
- `smd_strip4` (строка 872)
- `smd_strip1` (строка 916)

### Шаг 3: Инвертировать Header

**Файл:** `firmware/src/pulhra/sm_draw.c:162` (`smd_header`)

**Изменения:**

1. **Фон канваса:** `smd_begin(0, SMD_HDR_Y, 240u, SMD_HDR_H, T_TEXT)` — белый фон

2. **Инвертировать цвета текста** — заменить `T_TEXT` ↔ `T_BG` во всех вызовах `sm_px_text`:

| Элемент | Было (ink, inv) | Стало (ink, inv) | Пояснение |
|---------|-----------------|-------------------|-----------|
| Трек (T1) | `T_TEXT, muted` | `T_BG, muted` | Чёрный текст; muted = белый на чёрном |
| KEYS | `T_TEXT, 1` | `T_BG, 1` | Инвертирован = белый текст на чёрном |
| Октава | `T_TEXT, 0` | `T_BG, 0` | Чёрный текст |
| Машина (SAW) | `T_TEXT, 0` | `T_BG, 0` | Чёрный текст |
| Пресет (03) | `T_TEXT, 0` | `T_BG, 0` | Чёрный текст |
| PLAY/STOP иконка | `T_TEXT, 0` | `T_BG, 0` | Чёрная иконка |
| BPM (120.0) | `T_TEXT, 0` | `T_BG, 0` | Чёрный текст |
| REC/ARM | `T_TEXT, 1` | `T_BG, 1` | Инвертирован = белый на чёрном |
| Паттерн (A01) | `T_TEXT, chain` | `T_BG, chain` | Чёрный текст; chain = белый на чёрном |

3. **Сообщения** (строка 182): `sm_px_text(..., T_TEXT, 1)` → `sm_px_text(..., T_BG, 1)`

### Шаг 4: Инвертировать Strip (одна дорожка)

**Файл:** `firmware/src/pulhra/sm_draw.c:909` (`smd_strip1`)

**Изменения:**

1. **Фон канваса:** `smd_begin(0, SMD_STRIP_Y, 240u, SMD_STRIP_H, T_TEXT)` — белый фон

2. **Инвертировать цвета точек:**

| Элемент | Было | Стало | Пояснение |
|---------|------|-------|-----------|
| Триг (залитая точка) | `T_TEXT` | `T_BG` | Чёрная точка на белом |
| REST (полая точка) | `T_TEXT` контур, `T_BG` центр | `T_BG` контур, `T_TEXT` центр | Чёрный контур, белый центр |
| **Тактовый индикатор** (i%4==0) | `SM_DIM_INK` | `SM_DIM_INK` | **НЕ МЕНЯТЬ** — тусклый серый виден на любом фоне |
| Плейхед (полоска внизу) | `T_TEXT` | `T_BG` | Чёрная полоска |
| Удержанный шаг (полоска вверху) | `T_TEXT` | `T_BG` | Чёрная полоска |
| Номер страницы (P1/P2) | `T_TEXT, inv=b` | `T_BG, inv=b` | Чёрный текст; P2 инвертирован |
| Длина трека | `T_TEXT, 0` | `T_BG, 0` | Чёрный текст |

### Шаг 5: Инвертировать Strip MIXER (4 дорожки)

**Файл:** `firmware/src/pulhra/sm_draw.c:868` (`smd_strip4`)

**Изменения:**

1. **Фон канваса:** `smd_begin(0, SMD_STRIP_Y, 240u, SMD_STRIP_H, T_TEXT)` — белый фон

2. **Инвертировать цвета:**

| Элемент | Было | Стало |
|---------|------|-------|
| Триг (точка 3×3) | `ink` (T_TEXT или SM_DIM_INK) | `ink` (T_BG или SM_DIM_INK) |
| REST (полая) | `ink` контур, `T_BG` центр | `ink` контур, `T_TEXT` центр |
| Тактовый индикатор | `SM_DIM_INK` | `SM_DIM_INK` (не менять) |
| Плейхед (полоска) | `ink` | `ink` (но ink теперь T_BG) |
| Тик выбранного трека | `T_TEXT` | `T_BG` |

**Логика `ink` для MIXER strip:**
```c
// Было:
uint16_t ink = (uint16_t)(((mute >> t) & 1u) ? SM_DIM_INK : T_TEXT);
// Стало:
uint16_t ink = (uint16_t)(((mute >> t) & 1u) ? SM_DIM_INK : T_BG);
```

### Шаг 6: Проверить `sm_px_ring` на совместимость

**Файл:** `firmware/src/pulhra/sm_px.c:58`

Функция `sm_px_ring` используется только в зоне Knobs (y 48..159), которая **НЕ ИНВЕРТИРУЕТСЯ**. Изменения не требуются.

### Шаг 7: Проверить все страницы

Header и Strip отрисовываются одинаково для ВСЕХ страниц:
- EDIT 1/2, AMP, MIX, FILTER, F.ENV, STEP
- MIXER, CLOCK, ARP, ARP 2
- FX, DIST, INSERT, VOICE, DLY, REV, CHORUS, EUCLID
- MENU, MIDI, SETUP
- Слои EDIT/GLO/SEQ (layer map перекрывает knobs, но header/strip остаются)

Инверсия применяется глобально — не нужно менять логику для отдельных страниц.

## Риски и проверки

1. **Регрессия `sm_px_text`:** Замена `T_BG` на `cv_bg` в `sm_px_text` (шаг 1) меняет поведение для ВСЕХ вызовов. Необходимо проверить, что ни один вызов с `inv=1` не используется на нестандартном фоне. В текущем коде `inv=1` используется только в header и strip — после их инверсии всё будет корректно.

2. **Тактовые индикаторы:** Используют `SM_DIM_INK = 0x4208` (тусклый серый). На белом фоне (0xFFFF) этот серый будет виден, но возможно потребуется корректировка оттенка для лучшей видимости.

3. **MIXER strip:** Проверить, что `smd_strip4` корректно отображается на белом фоне, особенно REST точки (полый контур).
