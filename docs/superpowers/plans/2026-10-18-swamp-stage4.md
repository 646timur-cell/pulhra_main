# SWAMP MACHINE — этап 4: эффекты, мастер, SAVE, MIDI, меню

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Страницы эффектов (FX-посылы, DIST, INSERT трека, глобальные DLY/REV/CHORUS), мастер-шина (2 инсерта, компрессор, дакер, SCOPE), страницы SAVE (проект — 40 паттернов; USER-пресеты), MIDI clock/CC/program change, меню (HOME держать).

**Architecture:** Приложение `firmware/src/swamp/` на ядре MONOFM. Владение: главный цикл — единственный писатель `smp`; ISR читает и владеет `trk[]`, транспортом, секвенсором. Параметры трека (посылы, DIST, INSERT) — в `p[]` кита (уже есть в TP). **Мастер и глобальные эффекты — уровень проекта, не паттерна** (спек, раздел 3: «Проект: … мастер (компрессор, дакер, глобальные FX)») — в маленьком объекте проекта рядом с BPM/swing; формат банков не растёт.

**Spec:** `docs/superpowers/specs/2026-10-16-monofm2-fork-design.md` (разделы 6, 7, 9). **Plan stage 3:** «Carry to stage 4».

## Global Constraints

- Ветка `swamp`; трейлер Opus 5.5 (`context.md`); без force-push. Нет `#if FELUCCA_*` в `swamp/`.
- RAM headroom ≥ 4096 B (сейчас 7664), pool ≥ 8192 B.
- Флеш SWAMP только `0xB4000…0xDC000` (+ USER-пресеты — см. Task 3); запись только на стопе.
- Формат банков не меняется (мастер/глобальное — в объекте проекта; объект проекта — с версией и миграцией старой версии: новые поля по умолчанию).
- Сообщения только из разрешённого списка; вид mk1.
- ISR: новые DSP-блоки (мастер-инсерты, компрессор) — без делений на сэмпл; оценка стоимости в тесте CPU (`tests/monofm_cpu.sh`-аналог или счётчик инструкций хоста), не хуже +15 % к текущему блоку.

### Task 1: Страницы эффектов трека и глобальные эффекты

- Семейство FX (тап листает): **FX** — K1–K4 посылы DIST / CHO / DLY / REV (`P_DIST..P_REV`), SELECT — DRY (уровень сухого, если есть в ядре; иначе — глобальный MIX дилея); **DIST** — тип, DRIVE, TONE, LVL (параметры ядра MONOFM: `P_DTYPE` и соседи, см. `params.c`), SELECT — LCUT; **INSERT** — TYPE (OFF, CRUSH, PHASR, FLANG, CHOR — без драйвов), A, B, C, SELECT — MIX; **FX + SELECT** (держать FX, крутить SELECT) — глубокие глобальные страницы: DLY (TIME, FDBK, COLOR, MIX), REV (TYPE, SIZE, DAMP), CHORUS (RATE, DEPTH) — значения `song.g[G_*]`, хранятся в объекте проекта.
- Локи работают на параметрах трека этих страниц (как везде); глобальные — без локов.
- [ ] Tests: каждый посыл слышен в мокрой шине; DIST типы меняют спектр; INSERT типы (и что драйвов нет в списке); глобальные значения переживают save→reboot→load; лок посыла на шаге.

### Task 2: Мастер-шина — 2 инсерта, компрессор, дакер, SCOPE

- Цепь: сумма + возвраты → **INS 1 → INS 2** (все типы INSERT, вкл. драйвы; стерео; реюз `ins_*` DSP или порт) → **компрессор** (THRESH, RATIO, ATK, REL, MAKEUP, MIX; детектор пиковый/RMS, сайдчейн — сумма) → лимитер ядра → выход.
- **Дакер:** источник OFF / TEMPO 1/4 / T1 (триги трека 1), DEPTH, RELEASE, маска треков (по умолчанию T2–T4); огибающая дакера умножает треки маски до суммы.
- Страницы: FX > MASTER INS (K1–K4 = INS 1 TYPE A B C; SELECT — переключить правку на INS 2; MIX — на SELECT в режиме INS 2 не нужен: MIX каждого инсерта — 4-я страница? — **решение:** две страницы MASTER 1 и MASTER 2, у каждой K1–K4 TYPE A B C, SELECT — MIX); HOME > COMP (K1–K4 THRESH RATIO ATK REL, SELECT — вкл/выкл; на экране — уровень входа, порог, gain reduction полосками); HOME > DUCK (K1 SRC, K2 DEPTH, K3 REL, K4 маска); HOME > SCOPE (осциллограф выхода).
- Все параметры мастера — объект проекта.
- [ ] Tests: инсерты слышны и обходятся при OFF; компрессор снижает пик при громком входе (GR > 0) и прозрачен ниже порога; дакер TEMPO 1/4 на 120 BPM — провалы каждые 0,5 с на треках маски, T1 не затронут; SCOPE рисует; CPU-бюджет.

### Task 3: Страницы SAVE — проект и USER-пресеты

- Семейство SAVE (тап листает): **PROJECT** — ALGORITHM листает 40 паттернов (A01…E08, занят/пуст, текущий), K1 мастер-длина, K2 режим смены, OCT+ — перейти, SEQ+F#5 / здесь F#5 держать — SAVE; **USER** — 64 слота звука трека: ALGORITHM / PRESETS листают, OCT+ — загрузить в выбранный трек (через модель + SMC_LOAD), F#5 держать — сохранить звук трека в слот; имя слота = машина + номер. На HOME/USER ALGORITHM — пресеты трека (спек).
- Флеш USER: найти свободное место (не `0xB4000…0xDC000`, не OTA, не зону сцен STRANGE, если её можно отдать — **решение исполнителя с обоснованием**, `_Static_assert` адресов); формат свой с CRC; 2 копии.
- [ ] Tests: список паттернов на PROJECT; save/load USER-пресета с перезагрузкой; обрыв питания.

### Task 4: MIDI — clock, CC, program change

- **Clock:** MENU CLOCK SRC: INT / USB / TRS; при внешнем — темп и старт/стоп от 0xF8/0xFA/0xFB/0xFC, сглаживание; INT — отправка clock + start/stop на USB и TRS (если есть выход). Реюз `midi_clock.c` если подходит (иначе свой разбор в `sm_midi.c`).
- **CC (Elektron-стиль, фиксированная карта)** на канале трека: CC → параметры страниц (таблица в `sm_midi.c`, задокументировать в SWAMP.md); приём меняет модель (главный цикл) + SMC_PARAM; при REC + игра — пишет локи как ручка.
- **Program change** на канале трека 1 (или авто-канал) → паттерн 0–39.
- [ ] Tests: внешний клок 120 BPM → шаги на месте ±CTL; start/stop; CC пишет параметр и лок при REC; PC переключает паттерн.

### Task 5: Меню (HOME держать)

- Строки (PRESETS листает, K1 значение): LEDS (OFF / DIM LO / DIM HI / INV), HOLD (300–600 мс), CLOCK SRC (INT/USB/TRS), CLOCK OUT (ON/OFF), MIDI CH T1–T4 (1–16), CC IN (ON/OFF), PC IN (ON/OFF), KEY VEL (фикс. громкость клавиатуры 1–127), ABOUT (версия, SOURCE_COMMIT). Хранение — в записи настроек (`settings_persist.c`, как этап 1) или своём объекте; без `#if`.
- [ ] Tests: каждая настройка применяется и переживает перезагрузку.
