# PULHRA — этап 4: эффекты, мастер, SAVE, MIDI, меню

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Страницы эффектов (FX-посылы, DIST, INSERT трека, глобальные DLY/REV/CHORUS), мастер-шина (2 инсерта, компрессор, дакер, SCOPE), страницы SAVE (проект — 40 паттернов; USER-пресеты), MIDI clock/CC/program change, меню (HOME держать).

**Architecture:** Приложение `firmware/src/pulhra/` на ядре MONOFM. Владение: главный цикл — единственный писатель `smp`; ISR читает и владеет `trk[]`, транспортом, секвенсором. Параметры трека (посылы, DIST, INSERT) — в `p[]` кита (уже есть в TP). **Мастер и глобальные эффекты — уровень проекта, не паттерна** (спек, раздел 3: «Проект: … мастер (компрессор, дакер, глобальные FX)») — в маленьком объекте проекта рядом с BPM/swing; формат банков не растёт.

**Spec:** `docs/superpowers/specs/2026-10-16-monofm2-fork-design.md` (разделы 6, 7, 9). **Plan stage 3:** «Carry to stage 4».

## Global Constraints

- Ветка `pulhra`; трейлер Opus 5.5 (`context.md`); без force-push. Нет `#if FELUCCA_*` в `pulhra/`.
- RAM headroom ≥ 4096 B (сейчас 7664), pool ≥ 8192 B.
- Флеш PULHRA только `0xB4000…0xDC000` (+ USER-пресеты — см. Task 3); запись только на стопе.
- Формат банков не меняется (мастер/глобальное — в объекте проекта; объект проекта — с версией и миграцией старой версии: новые поля по умолчанию).
- Сообщения только из разрешённого списка; вид mk1.
- ISR: новые DSP-блоки (мастер-инсерты, компрессор) — без делений на сэмпл; оценка стоимости в тесте CPU (`tests/monofm_cpu.sh`-аналог или счётчик инструкций хоста), не хуже +15 % к текущему блоку.

### Task 2: Мастер-шина — 2 инсерта, компрессор, дакер, SCOPE

- Цепь: сумма + возвраты → **INS 1 → INS 2** (все типы INSERT, вкл. драйвы; стерео; реюз `ins_*` DSP или порт) → **компрессор** (THRESH, RATIO, ATK, REL, MAKEUP, MIX; детектор пиковый/RMS, сайдчейн — сумма) → лимитер ядра → выход.
- **Дакер:** источник OFF / TEMPO 1/4 / T1 (триги трека 1), DEPTH, RELEASE, маска треков (по умолчанию T2–T4); огибающая дакера умножает треки маски до суммы.
- Страницы: FX > MASTER INS (K1–K4 = INS 1 TYPE A B C; SELECT — переключить правку на INS 2; MIX — на SELECT в режиме INS 2 не нужен: MIX каждого инсерта — 4-я страница? — **решение:** две страницы MASTER 1 и MASTER 2, у каждой K1–K4 TYPE A B C, SELECT — MIX); HOME > COMP (K1–K4 THRESH RATIO ATK REL, SELECT — вкл/выкл; на экране — уровень входа, порог, gain reduction полосками); HOME > DUCK (K1 SRC, K2 DEPTH, K3 REL, K4 маска); HOME > SCOPE (осциллограф выхода).
- Все параметры мастера — объект проекта.
- [ ] Tests: инсерты слышны и обходятся при OFF; компрессор снижает пик при громком входе (GR > 0) и прозрачен ниже порога; дакер TEMPO 1/4 на 120 BPM — провалы каждые 0,5 с на треках маски, T1 не затронут; SCOPE рисует; CPU-бюджет.

### Task 3: Страницы SAVE — проект и USER-пресеты

- Семейство SAVE (тап листает): **PROJECT** — ALGORITHM листает 40 паттернов (A01…E08, занят/пуст, текущий), K1 мастер-длина, K2 режим смены, OCT+ — перейти, SEQ+F#5 / здесь F#5 держать — SAVE; **USER** — 64 слота звука трека: ALGORITHM / PRESETS листают, OCT+ — загрузить в выбранный трек (через модель + SMC_LOAD), F#5 держать — сохранить звук трека в слот; имя слота = машина + номер. На HOME/USER ALGORITHM — пресеты трека (спек).

### Task 4: MIDI — clock, CC, program change

## Пересборка управления по списку Тима (18.10, 10:17) — `claude/PULHRA-ROADMAP.md`

### Task 1A: Управление — SHIFT, клавиатура, LATCH, выбор трека
- OCT− = SHIFT везде, кроме режима игры на клавиатуре. SHIFT + ручка — **ускорение** (×4/×8 для широких диапазонов; заменяет «точную правку» этапа 3). SHIFT + HOME — меню (Task 5); SHIFT + SAVE — быстрое сохранение (как SEQ+F#5); SHIFT + FX — глубокие страницы эффектов по очереди (вместо FX+SELECT); SHIFT + EDIT — войсинг (страница VOICE уходит из EDIT); SHIFT + SEQ — евклид (страница-заглушка, если евклида ещё нет: настройки STEPS/HITS/ROT, генерация тригов в трек); SHIFT + D#… в степ-режимах: D#3 / F#3 — сдвиг дорожки на шаг назад / вперёд, D#4 / F#4 — транспоз −/+ (полутон); значения сдвига/транспоза показать в шапке трека на 1 с и на карте SHIFT.
- Режим клавиатуры — только OCT− + OCT+ (вкл/выкл); ARP больше не включает клавиатуру (тап ARP — только страницы ARP). Рядом с KEYS — сдвиг октавы (`KEYS +2`).
- ARP держать + F3 (первая белая) — LATCH нот трека независимо от арпа (держит ноты клавиатуры, как пэд; ещё раз — отпустить).
- HOME держать + белые F3…B3 — выбор трека T1–T4 (кроме ALGORITHM).
- OCT+ в степ-режимах: страница шагов 1–16 / 17–32 с понятной индикацией (полоса показывает номер страницы крупно, неактивная половина не рисуется).
- [ ] Tests на каждую комбинацию; старые тесты SHIFT/ARP/клавиатуры обновить.
