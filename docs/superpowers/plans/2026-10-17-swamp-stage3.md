# SWAMP MACHINE — этап 3: паттерны, цепочки, сохранение

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 16 паттернов с китами и их смена во время игры, цепочки, копирование/очистка/UNDO, FILL, видимая длина трека, сохранение проекта во флеш (2 копии + автосейв), страница SAVE (PROJECT, USER-пресеты).

**Architecture:** Прежнее приложение `firmware/src/swamp/`. Правило владения: главный цикл — единственный писатель `smp`; ISR читает `smp`, владеет `trk[]`, транспортом и состоянием секвенсора. Смена паттерна: главный цикл пишет запрос `smp.next`; ISR на границе решает и пишет своё `sm_play_pat` (+ грузит киты 4 треков через `sm_track_load` из `smp.pat[next].kit`); главный цикл видит `sm_play_pat` и обновляет `smp.cur`.

**Tech Stack:** как в этапах 1–2.

**Spec:** `docs/superpowers/specs/2026-10-16-monofm2-fork-design.md` (разделы 3, 4 «Цепочки», «SEQ-слой», 5 «SAVE», 9).

### Task 4 (переработан под банки, Тим 02:43): банки паттернов и сохранение

Концепция из `claude/SCENES-BANKS.md` (STRANGE), вариант A: **5 банков A–E × 8 паттернов = 40 (A1…E8); кит намертво в паттерне.** В RAM — паттерны текущего банка (8 вместо 16 → освобождается ≈ 20 КБ), остальные банки во флеше.
- GLO зажат + чёрные G#4 / A#4 / C#5 / D#5 / F#5 — банк A–E; GLO + белые G4…G5 — паттерн 1–8 банка. Тап по пустому — сохранить в него текущий паттерн (копия с китом); тап по занятому — переключиться на него (запрос `smp.next`, как SEQ+ALGORITHM, режимы смены прежние); удержание ≥ 800 мс — пересохранить текущий в этот слот (без переключения). LED слоя GLO: текущий паттерн горит, занятые дышат; выбранный банк горит, остальные дышат. Экран слоя: 8 ячеек `A1…A8` и ряд `A B C D E`.
- SEQ + ALGORITHM листает все 40 (A01…E08); переключение на паттерн другого банка подгружает банк (8 паттернов из флеша, копия ≈ memcpy) **до** запроса смены; ISR читает только паттерны в RAM. Цепочки — до 16 звеньев из любых паттернов; звено из другого банка: банк подгружается заранее, на предыдущем звене (если не успели — смена ждёт).
- Флеш: банк = 8 × `sm_pattern_t` ≈ 20 КБ (5 секторов + заголовок), 5 банков × 2 копии + рабочая копия текущего; разместить в области `0xB4000…0xDC000` (160 КБ) — посчитать и закрепить адреса `_Static_assert`; запись только на стопе; заголовок `{magic "SWB1", version, bank, seq, size, crc32}`; при старте — по каждому банку новейшая целая копия; маска занятости 40 бит в RAM. Глобальное (BPM, swing, мьюты, цепочка, текущий паттерн) — отдельный маленький объект проекта.
- SEQ + F#5 держать 0,8 с — SAVE всего (текущий банк + проект); автосейв — 8 с тишины на стопе.
- Tests: GLO-сетка (сохранить в пустой, переключиться, пересохранить удержанием), переход в другой банк во время игры (без пропуска шагов, банк подгружен заранее), цепочка через банки, обрыв питания при записи банка, полный круг save→reboot→load (киты, триги, локи, длины, BPM, swing, мьюты, цепочка), RAM headroom ≥ 4096.
