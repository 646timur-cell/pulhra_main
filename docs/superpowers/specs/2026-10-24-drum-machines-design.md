# PULHRA: драм-машины и KIT-трек (спецификация)

24.10.2026. Статус: на согласовании.

## Что сказал Тим

- Отдельные машины драм-синтеза: **KICK** (по мотивам Analog Rhythm), **SNARE**, **CLAP**, **HAT** (открытый / закрытый по переключателю), **CYM**.
- Синтез — новые движки со своим DSP, а не надстройка над DRUM Felucca.
- Если на **T4** загружена драм-машина **KIT**, секвенсор трека становится 4-дорожечным. Только T4, чтобы структура была жёстче.
- Линии KIT выбираются из драм-машин. Активная линия выбирается ручкой **ALG**.

## Допущения (поправь, если не так)

- В EDIT появляется четвёртая страница машин **DRUM**: KICK, SNARE, CLAP, HAT, CYM, KIT (белые F3…A3 и B3).
- **KIT** выбирается только на T4. На T1–T3 его клавиша тёмная, нажатие ничего не делает. Одиночные KICK…CYM ставятся на любой трек.
- У каждой машины 9 значений: E1…E8 на двух страницах EDIT и девятое на SELECT, как у остальных машин MONOFM.
- Старые банки и проекты не ломаются: новые машины добавляются в конец списка, номера старых не меняются.

## 1. Одиночные машины

Набор параметров у каждой — черновой, уточним при прослушивании.

### KICK

Синус со свипом высоты в две стадии (атака и тело), удержанием и драйвом.

| Параметр | Что делает |
|---|---|
| TUNE | Высота тела |
| SWEEP | Глубина свипа |
| STIME | Время свипа |
| DECAY | Затухание |
| HOLD | Удержание до спада |
| DRIVE | Мягкий клип / фолд |
| CLICK | Транзиент |
| NOISE | Шум в атаке |
| SELECT: TYPE | Форма тела: SINE / TRI / ROUND (больше гармоник) |

### SNARE

Две оболочки (основной тон и обертон с детюном) плюс шум через полосовой фильтр, раздельные огибающие.

| Параметр | Что делает |
|---|---|
| TUNE | Высота |
| DETUNE | Второй тон |
| DECAY | Тело |
| NOISE | Уровень шума |
| NDECAY | Затухание шума |
| NTONE | Центр полосового фильтра |
| SNAP | Транзиент |
| DRIVE | Драйв |
| SELECT: SWEEP | Свип тела |

### CLAP

Шум через полосовой фильтр, повторный удар N раз с интервалом SPREAD, затем хвост.

| Параметр | Что делает |
|---|---|
| TONE | Центр фильтра |
| Q | Резонанс |
| COUNT | 1–6 ударов |
| SPREAD | Интервал |
| DECAY | Хвост |
| TAIL | Уровень хвоста |
| HUMAN | Разброс ударов |
| DRIVE | Драйв |
| SELECT: TUNE | Высота |

### HAT

Металлический кластер из шести квадратов (или шум, или FM), полосовой и высокочастотный фильтры.

| Параметр | Что делает |
|---|---|
| MODE | CL / OP — переключатель. Закрытый глушит открытый на том же треке |
| TUNE | Высота |
| DECAY | Затухание: своё для CL и для OP, крутится то, что выбрано в MODE |
| TONE | Высокочастотный фильтр |
| Q | Резонанс |
| SIZZLE | Сизл |
| METAL | Источник: 6SQ / NOISE / FM / MIX |
| DRIVE | Драйв |
| SELECT: DECAY | Затухание |

### CYM

Широкий кластер через два полосовых фильтра, удар и звон.

| Параметр | Что делает |
|---|---|
| TUNE | Высота |
| DECAY | Затухание |
| TONE | Баланс высоких и низких |
| SPREAD | Детюн кластера |
| STRIKE | Удар |
| BELL | Колокол райда |
| NOISE | Шум |
| TYPE | CRASH / RIDE / CHINA |
| SELECT: HP | Высокочастотный фильтр |

Общее для всех машин:

- Велосити и акцент работают.
- Голос моно: новый удар перезапускает старый.
- Лок любого параметра работает как у остальных машин.
- CPU: один голос на трек, ориентир — не дороже нынешнего DRUM на ту же партию.

## 2. KIT на T4

**Звук.** Четыре линии, в каждой одна из драм-машин (по умолчанию BD SD HH CP). На линии работают параметры её машины по умолчанию плюс собственные **TUNE**, **DECAY** и **LEVEL** линии.

- Страница EDIT 1: TUNE и DECAY линий 1–4.
- Страница EDIT 2: LEVEL линий 1–4.
- SELECT: машина активной линии. Её можно сменить.

Типы и уровни линий хранятся в слотах параметров, которые драм-машинам не нужны (слоты F.ENV). Значит, это обычные параметры: едут с паттерном, локаются, сохраняются в банк. Формат банка не меняется.

**Шаги.** У шага уже есть четыре ноты (`note[4]`). На KIT-треке `note[i]` — удар линии i:

- 0 — нет удара;
- биты 0–6 — велосити;
- бит 7 — акцент линии.

Флаги шага (REST, RATCHET, SLIDE, NUDGE, условие) общие для всех линий этого шага. Формат банка не меняется. Если KIT сменить на другую машину, шаги остаются, но играют как ноты. Обратно на KIT — снова удары.

**Локи.** TUNE / DECAY / LEVEL каждой линии — отдельные параметры, поэтому лок на шаге действует на свою линию. Звук машины линии (её 9 значений) локается целиком для трека.

**Управление.**

- **ALG** проходит линии: … T3 → T4·BD → T4·SD → T4·HH → T4·CP → T1 …
- Шапка: `T4 BD` вместо `T4 KIT 01`.
- 16 белых клавиш ставят и снимают удары активной линии. Светодиоды показывают её же.
- Удержание трига + ручки на STEP редактируют этот удар. VEL — велосити линии, флаги — общие.
- На STEP вместо одной полосы — панель из четырёх ASCII-строк, как на MIXER. Активная линия подписана инверсией.
- На MIXER строка T4 показывает объединение: `•`, если бьёт любая линия.
- Режим клавиатуры на KIT: F3…B3 играют линии 1–4.

**Длина.** Длина T4 общая для линий, до 32 шагов. OCT+ листает 1–16 / 17–32 как обычно.

## 3. Этапы

Каждый этап — отдельная прошивка на проверку.

1. **KICK** и страница DRUM в EDIT. Тим слушает и правит параметры.
2. **SNARE** и **CLAP**.
3. **HAT** (CL/OP, чок) и **CYM**.
4. **KIT**: движок 4 линий на T4, шаги-удары, ALG по линиям, панель на STEP, шапка, светодиоды, сохранение.

Тесты на каждом этапе:

- хост-тесты звука: не молчит, не клипует, затухает до нуля, детерминирован;
- бюджет CPU на хосте;
- тесты UI / секвенсора.

## Не входит

- Пользовательские пресеты: позже.
- Сэмплы: только синтез.
- Пресеты машин: у каждой одна стартовая настройка (пресет 0) плюс 3–4 заводских, чтобы было с чего начать.
