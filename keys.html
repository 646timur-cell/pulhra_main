KNOBS

K1…K4
The four parameters of the page on screen
SELECT
The page's fifth parameter
ALGORITHM
Track T1–T4 (with SEQ held: picks a pattern)
PRESETS
Factory sound of the track's machine (trig held: the step FLAG)
MASTER
Output volume
SHIFT + knob
Coarse turn: ×4 / ×8 on wide ranges, 1 BPM a click on tempo

TRANSPORT & REC

PLAY
Start / stop
REC
ARM (step record): white keys become steps; knobs move the base only
HOLD REC + PLAY
Live record: played notes land on the nearest step; knob moves are recorded per AUTO (SHIFT + REC)
SAVE
PRESET page: load / save sounds, OCT+ confirms
SHIFT + SAVE
Save the project to flash (playing: at stop)
HOLD SAVE
UNDO the last edit (one level)

STEPS & TRIGS · REC armed

Tap F3…G5
Trig on / off (16 steps of the page in view)
HOLD key + knob
Parameter lock on that step (empty step: a trigless lock)
OCT− / OCT+ tap
Previous / next 16 steps (up to 64)
HOLD trig + REC
Copy that trig
HOLD trig + PLAY / OCT+
Paste the copied trig there
HOLD OCT+ + REC / PLAY
Copy / paste the 16-step page
SHIFT + white key
Lock trig (no note) on / off — REC on or off
HOLD trig + PRESETS
Step FLAG: ACC, SLD, ratchets X2–X4, REST…

STEP page (tap SEQ): K1 NOTE · K2 VEL · K3 LEN · K4 COND · SELECT track level · trig held + OCT−/OCT+ NUDGE. No step held: the track's trig defaults.

SHIFT · hold OCT−, outside keyboard mode

SHIFT + A#3 / C#4
Shift the track's trigs one step back / forward (KIT: the lane in edit)
SHIFT + D#4 / F#4
Transpose the track −1 / +1 semitone
SHIFT + HOLD D#5
Copy track (0.8 s)
SHIFT + HOLD F#5
Paste track (0.8 s)
SHIFT + G5
FILL while held (REC off)
SHIFT + REC
AUTO: what knobs record in live record — TRIG (trigs only) → ALL (empty steps get lock trigs) → OFF (also HOME → CLOCK K3)
